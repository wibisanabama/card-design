# Card Design

Card Design is a Flutter web project containing reusable examples of card-based user interface components.

## Requirements

- Flutter SDK compatible with Dart `>=3.4.4 <4.0.0`
- A supported web browser

## Setup

Install project dependencies:

```sh
flutter pub get
```

Run the project in a web browser:

```sh
flutter run -d chrome
```

## Build

Create a production web build:

```sh
flutter build web
```

The generated files are stored in `build/web`.

## Project Structure

- `lib/`: Flutter application source code and card components
- `assets/`: Image assets used by the components
- `web/`: Web platform configuration and static files
